## Sobre mim

Construo aplicações ponta a ponta com atenção à arquitetura, segurança, desempenho e experiência de uso. Meu foco atual está em **C#/.NET**, **React** e serviços integrados por APIs.

## Stack principal

- **Backend:** C#, .NET, ASP.NET Core, Entity Framework Core, REST APIs
- **Frontend:** React, JavaScript, Vite, TanStack Query, CSS
- **Dados e infraestrutura:** SQL Server, SQLite, Redis, Docker, Kubernetes
- **Qualidade:** xUnit, Vitest, React Testing Library, GitHub Actions
